# Salon - Luxury Beauty & Wellness ✨

**Salon** is a premium, modern, and fully responsive beauty salon website designed to provide a seamless user experience from discovery to booking. Featuring a sleek UI with smooth animations and an intuitive multi-step booking system.

---

## 🌟 Key Features

-   **💎 Premium Design:** Stunning visuals with glassmorphism effects and modern typography.
-   **📱 Fully Responsive:** Optimized for all devices—desktops, tablets, and smartphones.
-   **📅 Smart Booking System:**
    -   Multi-step booking flow (Services -> Professional -> Date & Time -> Details).
    -   Dynamic service selection with real-time price calculation.
    -   Preferred professional selection.
    -   Interactive date and time slot picker.
-   **✨ Smooth Animations:** Powered by **AOS (Animate On Scroll)** and **jQuery Scrollex** for an engaging browsing experience.
-   **📍 Informative Sections:** About Us, Contact, and specialized service highlights.

---

## 🚀 Tech Stack

-   **Frontend:** HTML5, Vanilla CSS3, JavaScript (ES6+)
-   **Libraries:** 
    -   [jQuery](https://jquery.com/) (DOM manipulation)
    -   [AOS](https://michalsnik.github.io/aos/) (Animations)
    -   [Font Awesome](https://fontawesome.com/) (Icons)
    -   [Google Fonts](https://fonts.google.com/) (Inter & Outfit)

## 🛠️ Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/GayathriSalini/Salon.git
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd Salon
    ```
3.  **Launch the website:**
    -   Simply open `home.html` in any modern web browser.
    -   Or use a local server like **Live Server** in VS Code.
